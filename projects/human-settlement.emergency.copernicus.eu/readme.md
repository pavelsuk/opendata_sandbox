# How to read and convert data about population from geotiff

## Data sources

- [GHS population grid (R2023)](https://human-settlement.emergency.copernicus.eu/download.php?dg=global_mt&ds=pop&epoch=2020&projection=4326&resolution=30ss)
    - Source: Pesaresi, M., Schiavina, M., Politis, P., Freire, S., Krasnodębska, K., Uhl, J. H., … Kemper, T. (2024). [Advances on the Global Human Settlement Layer by joint assessment of Earth Observation and population survey data](https://doi.org/10.1080/17538947.2024.2390454). International Journal of Digital Earth, 17(1).

## Requirements

- rasterio
  - Homepage on github (https://github.com/rasterio/rasterio)
  - Installation in conda
    ``` bash
    conda install conda-forge::rasterio
    ```
